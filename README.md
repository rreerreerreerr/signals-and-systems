# آزمایشگاه سیگنال و سیستم

سایت تعاملی فارسی برای یادگیری درس سیگنال و سیستم. پوشش آن از ابتدا تا بخش ۸.۷ کتاب زیر است (فصل‌های ۱ تا ۸، صفحهٔ ۲۵۰ فایل PDF):

> Fatoş Tunay Yarman Vural, Emre Akbaş. *Signals and Systems: Theory and Practical Explorations with Python*. Wiley, 2025.

## محتوا

| فصل | موضوع | نمونهٔ آزمایشگاه‌ها |
|---|---|---|
| ۱ | سیگنال و سیستم چیست؟ | شیفت و مقیاس گام‌به‌گام، تجزیهٔ زوج و فرد روی منحنی دلخواه |
| ۲ | آجرهای سازنده | مارپیچ مختلط، ضربه به‌عنوان حد، لگوی پله |
| ۳ | خواص سیستم‌ها | آزمایشگر خودکار خواص با امکان نوشتن سیستم دلخواه |
| ۴ | پاسخ ضربه و کانولوشن | کانولوشن با دنبالهٔ دلخواه، تشخیص تأخیر، تشخیص رقم |
| ۵ | معادلات دیفرانسیل و تفاضلی | کشیدن قطب‌ها، پدال و سرعت، بازگشت روی نمودار بلوکی |
| ۶ | سری فوریه پیوسته | سینت‌سایزر با صدا، چرخ‌های فوریه، پدیدهٔ گیبس |
| ۷ | سری فوریه گسسته | ویرایشگر ضرایب، جدول تعامد، تأیید خواص |
| ۸ | تبدیل فوریه پیوسته | گذر از سری به تبدیل، کاوشگر طیف، فیلتر کردن |

## اجرا روی کامپیوتر

سایت کاملاً ایستا است و به نصب یا بیلد نیاز ندارد:

```bash
python3 -m http.server 8000
```

بعد آدرس `http://localhost:8000` را باز کنید.

## ساختار

- `index.html` و `ch1.html` تا `ch8.html`: صفحه‌ها
- `assets/lib.js`: موتور نمودار، کنترل‌ها و آزمونک
- `assets/labs/`: آزمایشگاه‌های هر فصل
- `assets/vendor/`: KaTeX و فونت وزیرمتن، بدون وابستگی به CDN

## حق نشر

توضیح‌ها و شبیه‌سازها مستقل نوشته شده‌اند و متن یا شکل کتاب در این مخزن نیست. فایل PDF کتاب هم به‌دلیل حق نشر عمداً اضافه نشده است.

KaTeX با مجوز MIT و وزیرمتن با مجوز OFL استفاده شده‌اند؛ متن مجوزها کنار هر کدام در `assets/vendor/` است.
